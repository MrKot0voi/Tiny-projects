# Smooth Scroll (NeoForge 1.21.11)

Порт мода [Smooth Scroll](https://modrinth.com/mod/smooth-scroll) by SlovakSmileSK (GPL-3.0) с Fabric на NeoForge 1.21.11.
Лицензия: GPL-3.0 (см. `LICENSE`).

## Что портировано

- Конфиг на `ModConfigSpec` (раздел в экране конфигурации NeoForge), ключи и дефолты как в 2.6.7.
- Хотбар: плавный селектор, переполнение, статичный селектор, маска.
- Списки и поле ввода: плавная прокрутка `AbstractScrollArea` и `EditBox`.
- Подсказки команд: плавная прокрутка `SuggestionsList`.
- Чат: плавная прокрутка и сдвиг содержимого (`ChatComponent`).
- Креативное меню: плавная прокрутка и скольжение рядов (`CreativeModeInventoryScreen`, `CreativeSlotsMixin`).

## Что не портировано

- Точная (precise) маска: в оригинале это статический флаг `preciseScissor = false`, в конфиге его нет. По умолчанию используется обычный путь, он совпадает с Mojang, поэтому порт не нужен.
- Совместимость с CondensedInventory и Flow (в 2.6.7 она подключалась по наличию этих модов).
- Старый самописный экран конфига: его заменяет экран конфигурации NeoForge.

## Проверка

Сборка и запуск проверены в CI: клиент поднимается, подключается к локальному серверу и проходит сценарий чата, подсказок и креатива без ошибок миксинов. Ветка `runclient-test` содержит харнесс для этой проверки.

## Сборка

GitHub Actions: `.github/workflows/build-smoothscroll.yml`. Локально: `gradle build` в этой папке (нужен JDK 21).
